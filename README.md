# BipMe

BipMe is a creator-specific distribution-intelligence product, starting with X.

The first experimental milestone uses one authorized X account to validate the full intelligence workflow: importing creator history, building robust baselines, retrieving comparable posts, generating an evidence-backed Distribution Outlook, and comparing predictions with actual results.

## Development status

Project foundation and architecture decisions are underway. No public launch or multi-user scaling is planned for this initial stage.

## Core principles

- Creator-specific predictions grounded in observable data.
- Statistical baselines and auditable comparable-post evidence.
- Honest uncertainty, API access and pricing limits, and privacy safeguards.
- Start small and validate using real account data.

Architecture records will live under `docs/adr/`.
